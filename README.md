# 🏎️ Formula 1 Race Intelligence Platform

An end-to-end data analytics and web integration project designed to transform Formula 1 race data into actionable insights. This project embeds interactive Tableau visualizations into a custom Python Flask web application, making complex race metrics accessible to analysts, strategists, and fans.

## 🎯 Project Objective
The goal of this project is to process and visualize F1 datasets to uncover patterns in driver performance, circuit characteristics, and championship standings. By transitioning the analysis from a standalone Tableau workbook to an integrated web environment, the insights become highly shareable and centralized.

## 📊 Key Features & Analysis
* **Dynamic KPI Cards:** High-level metrics tracking total races, drivers, accumulated points, and DNFs (Did Not Finish).
* **Driver & Team Leaderboards:** Visual breakdown of point distributions and championship dominance.
* **Circuit Analytics:** Historical performance mapping across different international Grand Prix venues.
* **Interactive Filtering:** Users can dynamically filter the dashboard by specific teams, drivers, or seasons to isolate targeted intelligence.

## 🛠️ Technology Stack
* **Data Visualization:** Tableau Desktop, Tableau Public
* **Backend Framework:** Python 3, Flask
* **Frontend:** HTML5, CSS3 (Custom Dark Theme)
* **Deployment & Version Control:** Git, GitHub Pages

## 🚀 How to Run Locally
To run the Flask application on your local machine:
1. Clone this repository: `git clone <your-repo-url>`
2. Ensure Python is installed, then install Flask: `pip install flask`
3. Run the application: `python app.py`
4. Open a web browser and navigate to `http://127.0.0.1:5000`
